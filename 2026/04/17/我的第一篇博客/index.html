我的第一篇博客——如何搭建一个个人博客

Created2026-04-17|Updated2026-04-19
|Post Views:

1、安装环境
Node.js 和 Git
Node.js下载网址
https://nodejs.org/
选择版本： 你会看到两个按钮，请务必点击左边的 “LTS” 版本（长期支持版，最稳定）
Automatically install the necessary tools
Add to PATH
验证：
输入命令：node -v
再输入命令：npm -v

Git下载网址
https://git-scm.com/download/win
验证：
git –version

2、安装 Hexo 与初始化（建房）
npm install -g hexo-cli

切换到你的目录
hexo init my-blog

cd my-blog

3、安装依赖
npm install

4、博客本地启动
hexo server
running at http://localhost:4000

5、上线

  1. 在 GitHub 创建仓库
    登录 GitHub，点击右上角 + -> New repository。
    Repository name (仓库名)：必须填写 你的用户名.github.io（例如你的用户名是 tom，仓库名必须是 tom.github.io）。
    Visibility：选择 Public。
    点击 Create repository。

免密
ssh-keygen -t ed25519 -C “你的GitHub邮箱”
cat ~/.ssh/id_ed25519.pub
复制显示出来的以 ssh-ed25519 开头的一长串字符

添加到 GitHub：
进入 GitHub Settings -> SSH and GPG keys -> New SSH key，把复制的ssh-ed25519 开头的一长串字符粘贴进去，标题随便填，点击保存。

6、安装部署插件并上传
npm install hexo-deployer-git –save
npm install hexo-theme-butterfly

安装完成后，执行一键部署命令（清理缓存 + 生成静态文件 + 部署）：
hexo clean && hexo generate && hexo deploy

后续更新
hexo clean && hexo g && hexo d

登录博客
https://你的用户名.github.io
